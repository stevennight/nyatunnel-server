# 开发计划

背景与整体设计见 [设计方案](设计方案.md)。客户端仓库 `nyatunnel-client` 的进度在其 README 中同步。

## 已定决策（2026-10-03）

- 数据面自研：WebSocket（经 Caddy 443）+ yamux，不内嵌 frp
- 客户端：Go 核心 + CLI，GUI 用 Tauri 2 + React；全平台，Windows 优先
- 账号：管理员 + 普通用户，均支持 TOTP；普通用户默认一切需审批，可按用户开自助额度
- 部署：在已有 Caddy 之后运行；证书全部由 Caddy 管理（Cloudflare DNS-01 通配 + on-demand 自定义域名）
- 域名不写死：后台可配置多个隧道根域名和自定义域名
